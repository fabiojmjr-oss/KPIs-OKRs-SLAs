# Template — Ficha técnica de KPI

| Campo | Preenchimento |
|---|---|
| **ID** | ex.: `LM-001` (mesmo ID do catálogo) |
| **Nome** | |
| **Pergunta de negócio** | Que decisão este número apoia? |
| **Fórmula** | Numerador / Denominador, com filtros explícitos |
| **Unidade** | %, R$, h, un. |
| **Polaridade** | ↑ maior é melhor / ↓ menor é melhor |
| **Tipo** | Leading / Lagging |
| **Granularidade** | Por pedido, rota, turno, CD, região |
| **Frequência de cálculo** | Tempo real / diário / semanal / mensal |
| **Fonte de dados** | Sistema, tabela, campo |
| **Regras de exclusão** | O que não entra e por quê |
| **Linha de base** | Valor + período de referência |
| **Meta e limites** | Meta · Limite inferior/superior de controle (LIC/LSC) |
| **Benchmark externo** | Fonte + ano (⚠️ se indicativo) |
| **Métrica de contrapeso** | KPI que detecta otimização indevida |
| **Dono do resultado** | Nome/cargo |
| **Dono do dado** | Nome/cargo |
| **Visualização recomendada** | Carta de controle, série temporal, Pareto, etc. |
| **Versão / data** | v1.0 — AAAA-MM-DD |

## Notas de interpretação
- Como ler variações (sazonalidade, efeito calendário, mix).
- Quando o número engana.
